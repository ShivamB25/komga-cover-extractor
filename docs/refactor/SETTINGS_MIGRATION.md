# Settings migration

This reference preserves all 53 original `settings.py` rows and all 129 main-module initialization records, representing 128 distinct names. Original defaults remain visible. Of the 53 literal settings, 52 remain canonical configuration fields. The eager-cache boolean is recognized only during safe AST migration, validated, and omitted. [BASELINE_SETTINGS_ADDON.md](BASELINE_SETTINGS_ADDON.md) and [BASELINE_MAIN.md](BASELINE_MAIN.md) describe the frozen source consumers. Current ownership below follows the installed package, not those old captured globals.

All accepted behavior inputs use explicit CLI values > `KCE_*` environment > selected TOML > defaults. `Configuration.sources` records provenance. Root and scalar state/log paths resolve against the TOML parent for TOML values and invocation cwd for CLI/environment values. XDG/default paths resolve at load without creation. Absent flags never replace configured values. Authorization fields are not TOML/environment options.

`legacy_settings.migrate_settings` parses bounded AST literals and the complete reviewed `Keyword` class/constructor shape without importing or evaluating source. `resturcture_when_renaming` becomes `restructure_when_renaming`. Same-source spelling conflicts fail. Modern `--set` values are TOML literals. Repeatable roots/hooks retain order and modern root/subcommand flags have separate destinations.

Evidence keys bind rows to [SYMBOL_MIGRATION.md](SYMBOL_MIGRATION.md#evidence-keys). Final source tests pass 1,508 in145.51s; strict mypy64 files and frozen-excluded Ruff lint/export pass. Real release faults/CLI preserve counts/events; catalog and organizer work retain required evidence. Seven environments, actual image/layers, exact parts/26 commands and actual10/1000-book fivepairs pass. README/docs/eight frozen inputs package into a sdist building the unchanged tested runtime wheel. Historical1,502 receipts remain narrower. Formatting119 fails without a sweep; external/platform/history limits remain explicit.
